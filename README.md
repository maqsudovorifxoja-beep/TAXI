# 🚖 COBALT TAKSI (Atom Taxi Clone)

**Atom Taxi (`https://atomtaxi.vercel.app/`) — Chevrolet Cobalt taksisi simulyatori to'liq kloni.**

Toshkent ko‘chalari. Bitta mashina. Cheksiz smena. Rapier 3D fizika dvigateli, Three.js 3D grafikasi, haqiqiy audio effektlar, headunit radio stansiyalari, taksometr, yo'lovchi buyurtmalari va radar jarimalari bilan to'liq ishlaydi.

---

## 🎮 O'yin imkoniyatlari
- **Mashinalar to'plami (Cars Collection)**:
  - **Chevrolet Cobalt**: 1.5 B15D2, Oldi tortuvchi (FWD), 1250 kg, turbo kit o'rnatish imkoniyati.
  - **Mercedes-Benz C63 AMG**: 6.2L V8 atmosferik (457 ot kuchi / 600 Nm), Orqa tortuvchi (RWD), kuchli drift.
  - **BMW M5 G90 Sedan (2025)**: Rasmda ko'rsatilgan eng so'nggi dizayndagi M5 — **Frozen Deep Matte Black/Grey** bo'yoq, **Iconic Glow** yoritiladigan konturli radiator panjaralari, **vertikal dual-dagger LED faralar**, agressiv old trapesiya bamper, kengaytirilgan widebody qanotlar, M Carbon sopol oltin rang kaliperlar va 21 dyuymli Y-spoke qora disklar, 727 ot kuchi, 300+ km/soat.
- **AI Ko'cha Harakati (Traffic)**: Toshkent ko'chalarida harakatlanuvchi Cobalt va Spark avtomobillari — xilma-xil ranglar palitrasi bilan (qizil, yorqin sariq taksi, zumrad yashil, olovrang to'q sariq, moviy, feruza, kumush, qora, oq, binafsha va olcha ranglar).
- **Taksometr va Katta Daromadli Buyurtmalar**: Katta miqdordagi buyurtma to'lovlari (har bir buyurtma uchun 60,000 - 200,000+ so'mgacha daromad, minimal 5% komissiya, saxiy choychaqalar va tez pul ishlash).
- **wbAUDIO Radio Tizimi**: FM radio pleyeri — Asl Wayne, Abdulla Qurbonov, Sevara Nazarkhan, Mashhurbek Muhammad taronalari bilan.
- **Toshkent Ko'chalari va Tumanlari**: Real ko'cha nomlari, tezlik cheklovlari va radarlar.
- **Kamera Rejimlari**: Salon ko'rinishi, orqa kamera (R vitesda avtomatik orqa kamera), va erkin kuzatuv.

## ⌨️ Boshqaruv Tugmalari:

| Tugma | Vazifasi |
|---|---|
| **F** | **Mashinadan tushish / Mashinaga o‘tirish** *(GTA uslubida)* |
| **W / ↑** | Gaz (Tezlanish) / Piyoda: Oldinga yurish |
| **S / ↓** | Tormoz / Orqaga (R) / Piyoda: Orqaga yurish |
| **A / D / ← / →** | Rulni burish / Piyoda: Chapga-o‘ngga harakat |
| **Shift** | Piyoda: Yugurish (Sprint) |
| **Space (Probel)** | Mashinada: Qo'l tormozi / Piyoda: Sakrash (Jump) |
| **Backspace** | Mashinani yo'lga qaytarish |
| **P** | Haydovchi telefoni / buyurtmalar |
| **R / Shift+R** | Radio: Yoqish / Keyingi stansiya |
| **N** | Radio: Keyingi qo'shiq |
| **Tab** | Boshqaruv sozlamalari |
| **Esc** | Pauza menyusi |
